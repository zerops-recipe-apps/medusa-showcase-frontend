# medusa-showcase-nextstore

Next.js 16 showcase storefront (Yarn 3 Berry). Pairs with [medusa-showcase](https://github.com/zerops-recipe-apps/medusa-showcase).

- Zerops setups: `dev` (`deployFiles: ./`) and `prod`
- Port `8000`, readiness `/api/health`
- Project vault: `APP_URL`, `API_URL`, `CHANNEL_PUBLISHABLE_KEY`, `MEDUSA_HOST`, `RELOAD_SECRET`, search public URL when used
