# Medusa showcase Next.js storefront

Next.js 16 storefront for [zerops-recipe-apps/medusa-showcase](https://github.com/zerops-recipe-apps/medusa-showcase). Deploy with `zeropsSetup: dev` or `prod` from [`zeropsio/recipes/medusa-showcase`](https://github.com/zeropsio/recipes/tree/main/medusa-showcase).

Local: `yarn dev` on port 8000 against your Medusa `API_URL` and publishable key.
